# Spydra — brand

A crawler that sits quietly at the centre of a web and feels every thread.

The name does the work. The interface does not reinforce it with atmosphere —
no terminal green, no glow, no decorative webbing in the chrome. The metaphor
is carried once, by the logo, and never repeated.

**Design target:** a professional instrument. The visual register of a modern
analytics or infrastructure console, where restraint signals competence. The
mark should be at home next to a Datadog or Grafana logo, not on a Halloween
poster.

---

## Logo

A spider at rest on a web whose vertices are computers.

The web is drawn as **network topology**, not as decoration: six radial
strands, two polygonal chord rings, and a device glyph at each outer vertex.
Chords are straight, not curved — real orb webs are built from straight silk
between radials, and straight chords stay sharp at small sizes where a curve
turns to mush.

The spider is geometric, not naturalistic: two circles on the vertical axis
and eight legs as four mirrored pairs of two-segment strokes. No eyes, no
fangs, no hair. It is a weaver and a sensor, not a threat.

### Construction

Everything derives from one 64×64 lattice, documented in
[`design/logo/_geometry.md`](../design/logo/_geometry.md) and generated by
[`design/logo/build_logo.py`](../design/logo/build_logo.py).

Generating rather than hand-drawing each variant is what keeps the favicon a
true subset of the mark instead of a lookalike that drifts. Change the
geometry in one place and every variant follows:

```sh
python3 design/logo/build_logo.py
```

### Variants

| File | Use | Detail |
| --- | --- | --- |
| `spydra-lockup-horizontal.svg` | App header, documents | Mark + wordmark |
| `spydra-lockup-stacked.svg` | Splash, print, title slides | Mark above wordmark |
| `spydra-mark.svg` | Standalone, full colour | Full web + spider |
| `spydra-mark-adaptive.svg` | In-app (sidebar) | `currentColor`; follows the theme |
| `spydra-mono.svg` | Watermark, single-colour print | One ink |
| `spydra-favicon.svg` | Browser tab, OS icon | **Spider only** |

**The favicon drops the web entirely rather than shrinking it.** Below 24 px
the silk is thinner than a pixel and the six device nodes collapse into noise;
the spider is scaled 1.55× to fill the tile instead.

### Clear space and minimum sizes

- Clear space on all sides = one cap height of the wordmark (12 lattice units).
- Horizontal lockup: never below 120 px wide.
- Mark: never below 32 px. Below that, use the favicon variant.

### Colour

| Element | Token | Light |
| --- | --- | --- |
| Spider | `brand-700` | `#3730A3` |
| Device nodes | `brand-500` | `#4F56D9` |
| Web silk | `neutral-300` | `#CDD2DA` |

On dark surfaces use `spydra-mark-adaptive.svg`, which inherits `currentColor`
and renders the silk at 38% opacity. Never recolour the mark per-context by
hand.

### Wordmark

**Space Grotesk**, medium (500), −2% tracking. Used in the logo only — never
in the interface.

The SVG lockups reference the font by name rather than embedding outlines, so
they render correctly only where Space Grotesk is installed or loaded.
**Before using a lockup outside this repo — a slide, a PDF, a third-party
site — convert the text to outlines.** This is the one unfinished step in the
logo set, and it is deliberate: outlining early makes the wordmark
uneditable while the brand is still young.

### Avoid

- Gradients inside the spider, drop shadows, anything photoreal
- The horror register: red eyes, dark backgrounds, dripping anything
- Rotating or reflecting the mark — the top vertex is what makes it read upright
- Recolouring the spider to signal state. Colour means lifecycle state in this
  product, and the logo is not a status indicator
- Stretching either lockup. Scale both axes together
